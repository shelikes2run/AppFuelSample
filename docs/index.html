Current vegetation & drought near the selected site

Click a site on the map (or pick one in the list) to see the nearest live cameras and drought conditions there.

Cameras: ALERTCalifornia (UC San Diego; latest frame, refreshed every few minutes, CA) and the PhenoCam Network (vegetation-monitoring cameras across the U.S.; latest daily image). Drought: U.S. Drought Monitor (current week) and, in California, the UC Irvine CHRS drought forecast by river basin (MSDI = precipitation + soil moisture; SPI = precipitation only), the same layer as the CA Prescribed Fire Planner.
